About MyImgConvert

Simple image conversion with local processing and clearly explained trade-offs.

What this site provides

MyImgConvert is a collection of free browser tools for PNG, JPG and WebP conversion, resizing and compression. The site provides individual and batch downloads without requiring an account.

How the tools are built

The converter uses your browser to decode selected images, draw pixels to a canvas and encode new files. The conversion script and supporting assets are served with the page. There is no image conversion API or upload endpoint in the supplied site code.

What you can verify

You can inspect network activity while converting, compare actual file sizes and test transparency in the downloaded file. Our method and limitations page explains what is preserved, what may change, and how to check the processing yourself.

Who maintains the tools?

The tools and these explanations are maintained under the MyImgConvert name. We do not claim professional certifications, independent security certification or guaranteed compression results. For corrections or support, use our contact page.

Corrections and maintenance

Instructions should match the tool's actual behavior. If a browser update changes an encoder or a file fails to convert, report the browser, format and error so the behavior can be investigated. Do not send private images.
