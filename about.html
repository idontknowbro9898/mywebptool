About MyImgConvert

MyImgConvert is a set of free tools for converting and compressing images between WebP, JPG and PNG. It was built for people who want a quick result without creating an account or uploading personal photos to a stranger's server.

How the tools work

Each tool uses the image features already built into your web browser. Your file is read on your device, redrawn on a canvas in memory and saved in the new format. The result is handed back to you as a download. Because there is no upload step, conversion is fast and your files are not sent to us.

What the tools do not do

  • They remove metadata such as camera details and GPS location from converted files.
  • They convert only the first frame of animated images.
  • They cannot create WebP files in browsers that do not support it. The tool tells you when this applies.
  • They do not resize images. Resize first if you need smaller dimensions.
