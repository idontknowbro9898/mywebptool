    What changes when a PNG becomes a WebP

    PNG always stores every pixel exactly. This tool saves lossy WebP at the quality you choose, which discards detail that is hard to see. That is why screenshots and photographic PNG files often shrink a lot. Google's WebP documentation reports that lossless WebP files are about 26% smaller than PNG files, and lossy files go further.

    If you need an exact copy of every pixel, move the slider to 100. Chrome and Edge then create a lossless WebP. Other browsers may handle 100% differently, so check the size and preview.

    When you should keep the PNG

    • You will keep editing the image. Lossy formats lose a little more detail each time you save them.
    • You are working with pixel art or very small graphics where every pixel matters.
    • The software that will open the file does not support WebP. Some older editors and email programs do not.

    Using the WebP on your website

    Every current major browser can display WebP. For maximum safety, serve the WebP with a fallback to the original file. The format guide shows the HTML to do this.

    Frequently asked questions

    Does transparency survive the conversion?

    Yes. WebP supports transparency, so transparent areas of your PNG stay transparent.

    Which quality should I use for logos and icons?

    Start at 90. Flat colours and sharp edges show compression artifacts sooner than photos do. At 100% Chrome and Edge save a lossless WebP.

    Will the WebP always be smaller than the PNG?

    Usually, but not always. Very small or very simple PNG files can stay about the same size. The tool shows the exact result before you download, so you can keep whichever file is smaller.

    Can I convert many PNG files at once?

    Yes. Add up to 50 files and download them together as a ZIP.
